# MangaReader

MangaReader 是一个桌面优先的本地漫画阅读器，使用 Vue 3、TypeScript、Vite 与 Tauri 2 构建。漫画文件保留在用户选择的位置；应用只保存书目、阅读进度、书签和设置。

## 支持格式

- 图片目录：JPEG、PNG、WebP、GIF、AVIF、BMP
- PDF
- CBZ / ZIP
- CBR / RAR

目前不支持 EPUB、MOBI、CB7/7z、云同步或 AI 超分。

## 主要功能

- Tauri 原生文件与目录选择、递归扫描和稳定来源去重
- 文件缺失提示、来源重新关联、图片目录重新扫描与变更摘要
- 翻页与纵向滚动阅读、单/双页、LTR/RTL、三种适应方式和缩放拖动
- PDF 阅读、页码跳转、页快速浏览、边缘点击、滚轮与键盘操作
- 阅读进度、带备注书签、上一章/下一章、完读状态和全屏
- 书名、封面、标签和系列编辑；进度重置与批量移出书架
- 元数据、进度、书签和阅读设置的 JSON 备份/恢复（不复制漫画原文件）
- 亮色、暗色与跟随系统主题；减少动态效果支持
- 可选 USM 轻量锐化、亮度与色温调整
- 图片、PDF 与压缩包漫画的当前页翻译、气泡点读、双语对照侧栏、框选补译、原文纠错与本地缓存

## 翻译功能

图片通过本地 RapidOCR 识别，翻译服务只接收文字，无需图片模型。Windows 首次使用：

1. 安装 Python 3.10 或更新版本，并允许命令行调用 `python`。
2. 双击 `ocr/setup-ocr.cmd`，创建独立环境、安装识别依赖并下载日语、英语和简体中文模型。首次下载需要联网；模型缓存在 `ocr/models/`。
3. 双击 `ocr/start-ocr.cmd`，保持 OCR 服务运行；以后使用只需启动此脚本。默认地址为 `http://127.0.0.1:8876`，仅监听本机。
4. 打开漫画后点击顶部“翻译”，或按 `T`，在“翻译服务设置”中点击“检测 OCR”。桌面版安装好运行环境后可直接点击“启动 OCR”；浏览器版仍需启动脚本。可提前“准备所选语言模型”，并查看下载或加载状态。“测试文字翻译”使用一句日语问候单独检测文字接口，最后保存设置。

已支持的服务（免费额度按官方 2026 年 9 月说明；后续以服务商说明为准）：

| 服务 | 免费使用方式 | 接入要求 |
| --- | --- | --- |
| [MyMemory](https://mymemory.translated.net/doc/usagelimits.php) | 匿名每天 5,000 字符；提供有效邮箱后每天 50,000 字符 | 无需密钥，必须指定原文语言；可选邮箱会随请求发送 |
| [腾讯云文本翻译](https://cloud.tencent.com/document/product/551/35017) | 每月 500 万字符 | 开通服务，填写 SecretId、SecretKey 和地域；免费额度用完后是否计费取决于控制台配置 |
| [DeepL API Free](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans) | 每月 50 万字符 | API Free 账号和密钥，使用专用免费接口 |
| [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate) | 自托管的开源软件免费 | 另行部署文字翻译服务，安装所需语言模型；公共服务不保证免费 |
| 兼容 Chat Completions API | 取决于服务商 | 服务地址、文字模型名称和可选密钥；可连接本地文字模型 |

[微软 Translator F0](https://azure.microsoft.com/en-us/pricing/details/cognitive-services/translator/) 另有每月 200 万字符免费额度，当前未实现其专用适配器。

MyMemory 默认无需密钥即可试用；长期使用可选择腾讯云。兼容 API 地址可以填到 `/v1` 或完整 `/chat/completions` 路径。云端使用 HTTPS，本机服务支持 HTTP；OCR 地址仅接受回环地址。腾讯云请求已限制发送频率，MyMemory 按 UTF-8 字节分段，DeepL 按数量与请求大小分批。LibreTranslate 的 `zh` 为简体中文，繁体目标请选择其他服务。

选择原文与译文语言后，点击“翻译当前页”。原文语言决定 OCR 模型；“自动识别”使用日语 OCR，再由支持自动检测的文字服务判断语言。韩语、繁体中文和拉丁字母模型会在首次使用时下载。点击页面中的数字标记可查看译文，侧栏显示整页对照；“框选”用于补译遗漏区域。“查看原文”中可以纠正识别文字并重新翻译。兼容文字模型不支持 JSON 模式时，可以在高级选项中关闭该选项。浏览器开发模式需要翻译服务允许跨域请求；桌面版通过原生请求访问服务。

图片只发送给本机 OCR，识别结果再发送到所选文字服务。OCR 不保存图片、不记录请求内容，下载模型后可离线识别。API 密钥、腾讯云 SecretKey 和可选邮箱仅保存在本次会话中，重启或刷新页面后需重新填写；服务地址、文字模型、SecretId、地域与语言偏好会保存。译文缓存在独立的本地数据库中，可在侧栏清除此书缓存，移出书架时也会清理；元数据备份不包含译文或密钥。更换 OCR 或翻译服务后使用独立缓存，旧版图片模型结果不会误用。

浏览器模式下，腾讯云请求通过本机 OCR 服务的 `/translate/tencent` 接口转发，避免浏览器跨域拦截；本机服务只转发签名后的文字请求到固定的腾讯云文本翻译接口，不接收 SecretKey，不转发漫画图片，也不跟随重定向。桌面版仍通过原生请求访问腾讯云。升级后需重启 `ocr/start-ocr.cmd`。服务未开通、密钥无权限、签名过期和额度耗尽会显示对应原因、腾讯云错误码及请求编号。

日语 OCR 会按气泡合并竖排列与上下碎片，恢复列内自上而下、列间自右向左的顺序，并去掉物理换行造成的断句。气泡边框不完整或仅框选部分气泡时，会结合文字间距与分隔线判断是否合并；小字号振假名在能确认对应汉字时会过滤，避免重复识别。升级后使用新的缓存版本，已翻译页面可点击“重新识别本页”。

译文侧栏的“批量翻译”可选择页码范围，默认最多选择从当前页起的 10 页。任务逐页执行，可暂停、继续、取消和单独重试失败页；返回书库后继续运行，在书库顶部“翻译任务”查看。关闭应用后任务恢复为暂停状态，手动继续前需要重新填写本次会话的密钥。额度、鉴权或连接失败会自动暂停，避免连续发起无效调用。移除漫画或清除其缓存会取消相关未结束任务。

原文识别和译文分别保存，更换目标语言或文字服务可复用 OCR 原文与纠正结果。完整译文直接按来源版本读取，无需重复截图；老缓存首次使用时自动迁移。对白翻译逐段保存（兼容模型与 DeepL 按响应批次保存），重试只处理缺失对白。最近 500 份译文和 1000 份原文识别会保留，较早的缓存会自动清理，因此超长漫画重读早期页面可能重新请求文字翻译。

保留漫画原图，译文通过点读与侧栏展示。通用 OCR 对手写、装饰字体和复杂竖排仍可能漏字或错字，低置信度结果会标记为“识别存疑”，可框选并纠正原文。气泡分组和阅读顺序采用启发式规则；暂不提供原图擦字和译文排版。Windows 安装包包含 OCR 服务脚本；Python 运行环境仍需先运行安装脚本准备，安装版运行环境与模型保存在用户应用数据目录。

页缩略图按 240 像素生成，同一页共享生成任务，同时最多生成 3 张，可见预览不会被缓存清理提前释放。批量书库分页按漫画本数计算。浏览器压缩包在独立线程逐页解压并传递，压缩包上限 500MB、单页解压上限 128MB、图片解压总量上限 768MB；浏览器仍会展开整本漫画，超大文件建议使用桌面版按页读取。可恢复的页面缓存同时受到本数和 192MB 大小限制，未保存成功的会话文件不会被逐出。PDF 渲染限制为每个画布最多约 1200 万像素，跳页取消过期渲染；桌面端同时最多解码 4 个页面，RAR 共享解压锁，缓存空间扫描降低频率。

## 开发与验证

```bash
npm install
npm run dev          # 浏览器开发模式
npm run tauri dev    # 桌面开发模式（完整文件能力）
npm run check        # TypeScript / Vue 类型检查
npm run test:run     # 单元与组件测试
npm run build        # 类型检查 + PDF 解码资源同步 + 生产构建
npm run tauri build  # Windows NSIS 安装包
```

桌面窗口最小尺寸为 768×600。浏览器开发模式会把导入内容缓存到 IndexedDB；桌面模式保存原生路径，并按需读取图片页。

浏览器导入图片目录时会逐页保存字节缓存，刷新后按需读取页面，避免整本漫画同时占用内存。启动时根据实际缓存修正书目状态；有缓存的旧书目会自动清除错误的重新关联提示。旧版仅保存在会话中的图片目录，刷新后需要从书目菜单选择“重新导入”并选择原目录一次；直接重新导入同一目录也会恢复原书目，保留标题、标签、进度和书签。浏览器存储空间不足时会提示仅本次会话可用。

## 数据与迁移

- 书库 Dexie 数据库为 v4，图片页面、翻译识别与后台任务分别存放在独立数据库，升级保留既有书目与阅读进度。
- 旧 `input` 与 `fsa-*` 来源可以继续读取；需要时应用会要求重新授权或重新关联。
- 删除书目会同时删除其书签、浏览器缓存与解压内存缓存，但不会删除原漫画文件。
- “移出书架”和“删除源文件”是独立操作；删除源文件需要两次确认，图片目录只删除该书目的明确页文件，不递归删除目录。

## 快捷键

- `←` / `→`、`PageUp` / `PageDown`、空格：翻页
- `1` / `2`：单页 / 双页
- `L` / `R`：LTR / RTL
- `F`：切换适应宽、高、原大
- `B`：添加或移除当前页书签
- `T`：开启或关闭翻译模式
- `H`：显示或隐藏控制栏
- `Ctrl+Shift+F`：全屏
- `?`：快捷键面板
- `Escape`：关闭弹层或返回书库
